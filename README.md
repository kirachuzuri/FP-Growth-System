# 📊 Data Mining 期末作業：FP-Growth 關聯規則查詢系統

本專案實作了資料探勘（Data Mining）中的 **FP-Growth（Frequent Pattern Growth）演算法**，並結合 **Tkinter** 打造圖形使用者介面（GUI）。使用者可以透過直覺的介面輸入自訂的支援度與信賴度閾值，系統將自動從交易紀錄中挖掘出「頻繁項集」與「強關聯規則」。

---

## 🚀 功能特點

* **高效演算法實作**：使用 FP-Tree 結構壓縮交易資料，僅需掃描資料庫兩次，免去傳統 Apriori 演算法反覆掃描的效能瓶頸。
* **動態互動介面**：支援動態切換輸入「最小支持度計數（次數）」或「最小信賴度（比例）」。
* **靈活結果篩選**：可一鍵切換顯示模式（全部顯示、僅顯示頻繁項集、僅顯示強關聯規則）。
* **自動排序輸出**：
  * 頻繁項集依「支持度次數」由大到小降序排列。
  * 關聯規則依「信賴度與支持度」綜合降序排列，方便找出最具價值的黃金規則。

---

## 🛠️ 開發環境與核心技術

* **開發語言**：Python 3.12
* **核心套件**：
  * `tkinter` (內建 GUI 套件)
  * `itertools` (用於關聯規則的子集組合計算)
* **演算法核心**：
  1. **First Scan**：統計單一物品頻率，建立標頭表（Header Table）。
  2. **Build FP-Tree**：依頻率降序將交易紀錄插入 FP-Tree。
  3. **Conditional Pattern Bases**：透過節點鏈結（Node Link）向上追溯前綴路徑。
  4. **Mine FP-Tree**：遞迴挖掘條件樹，組合出所有頻繁項集。
  5. **Association Rules**：依據信賴度公式計算並篩選強關聯規則。
